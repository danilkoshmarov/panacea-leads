# Panacea Leads

Локальная CRM для самостоятельного поиска и ведения заказов.

## Запуск
Открой `index.html` в браузере. Node.js, npm, сервер и платные сервисы не нужны.

## Реализовано в 0.2.1
- Создание, редактирование и удаление заказов.
- Поиск, фильтр по статусу и сортировка по дате/бюджету.
- CRM-доска по этапам работы.
- Избранное.
- Сводные показатели и аналитика.
- Экспорт и импорт резервной копии JSON.
- Локальное хранение в localStorage.

## Чего пока нет
Автоматический сбор заказов из Telegram, RSS или сайтов ещё не подключён. Приложение не генерирует фиктивные лиды и не подтверждает актуальность контактов. Все записи добавляются вручную.

## Важно о данных
Данные хранятся в браузере на конкретном устройстве. Они не синхронизируются с GitHub. Перед очисткой браузера или переносом на другое устройство экспортируй резервную копию через «Настройки».

## Roadmap
1. Проверка бесплатных публичных источников и их правил.
2. Подключение первого источника.
3. Проверка актуальности объявлений и дедупликация.
4. Оценка эффективности источников на реальных результатах.
